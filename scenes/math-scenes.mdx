SwapTube ships a large library of purpose-built mathematical visualisation scenes, all living under `src/Scenes/Math/`. Each one extends either `Scene`, `CoordinateScene`, or `ThreeDimensionScene` (see [Common Scenes](/scenes/common-scenes) for those base classes) and is driven entirely by the `StateManager` — you animate every visual parameter by calling `manager.transition(...)` or `manager.set(...)` on the scene's `manager` member.

---

## Fractal Scenes

### `MandelbrotScene`

**Header:** `src/Scenes/Math/MandelbrotScene.h`  
**Inherits:** `CoordinateScene → Scene`

Renders the Mandelbrot set (or Julia sets) entirely on the GPU. The scene inherits the full `CoordinateScene` viewport (`center_x`, `center_y`, `zoom`) and adds fractal-specific parameters.

| State variable | Meaning |
|---|---|
| `pixel_param_z` | Weight of the pixel coordinate in the `z` seed (0 = fixed `z`, 1 = pixel as `z`) |
| `pixel_param_c` | Weight of the pixel coordinate in the `c` seed (0 = fixed `c`, 1 = pixel as `c`) |
| `seed_c_r` | Real part of the fixed `c` seed when `pixel_param_c` is 0 |
| `seed_c_i` | Imaginary part of the fixed `c` seed |

```cpp
#include "Scenes/Math/MandelbrotScene.h"

void render_video() {
    MandelbrotScene ms;
    ms.manager.set("zoom", ".2");
    ms.manager.transition(MICRO, {
        {"pixel_param_z", "1"},
        {"pixel_param_c", "0"},
        {"seed_c_r", ".4"},
        {"seed_c_i", ".1"},
    });
    stage_macroblock(SilenceBlock(4), 2);
    ms.render_microblock();
    ms.manager.transition(MICRO, "zoom", "1");
    ms.render_microblock();
}
```

### `Fractal2DScene`

**Header:** `src/Scenes/Math/Fractal2DScene.h`  
**Inherits:** `Scene`

A highly generalised 2-D fractal renderer that supports multiple iteration modes, selectable via the `fractalModes` enum:

| Mode constant | Description |
|---|---|
| `MANDELBROT_2` | Standard degree-2 Mandelbrot |
| `MANDELBROT_3` | Degree-3 Mandelbrot |
| `MANDELBROT_POWER` | Mandelbrot with a state-variable exponent |
| `MANDELBROT_XSET` | Xset / parameter-space variant |
| `REAL_COEFF_POLY` | Polynomial with real coefficients |
| `COMPLEX_COEFF_POLY` | Polynomial with complex coefficients |
| `COMPLEX_C_COEFF_POLY` | Polynomial with complex `c`-parameterised coefficients |

The scene exposes a helper for building parameter state sets:

```cpp
StateSet makeFractalStateSet(
    vector<float> params,
    const string& identifier,
    const int mode          // one of the fractalModes enum values
);
```

## Graph Scenes

### `GraphScene`

**Header:** `src/Scenes/Math/GraphScene.h`  
**Inherits:** `ThreeDimensionScene → SuperScene → Scene`

`GraphScene` is one of the most powerful scenes in SwapTube. It maintains a force-directed `Graph` data structure whose nodes and edges are projected into 3-D space and then rendered via the inherited `ThreeDimensionScene` camera. Physics simulation (repulsion, attraction, velocity decay) runs automatically during `change_data()`.

#### Physics State Variables

| Variable | Default | Meaning |
|---|---|---|
| `repel` | `1` | Node repulsion strength |
| `attract` | `1` | Edge attraction strength |
| `decay` | `.95` | Velocity decay per tick |
| `physics_multiplier` | `1` | Global physics speed scale |
| `dimensions` | `3` | Number of spatial dimensions for physics (1–4) |

#### Visual State Variables

| Variable | Default | Meaning |
|---|---|---|
| `edge_weights_size` | `0` | Font size multiplier for edge-weight labels |
| `node_labels_size` | `1` | Font size multiplier for node labels |
| `midpoint_multiplier` | `1` | Size of the directed-edge midpoint dot |

#### Camera Variables (inherited)

`q1`, `qi`, `qj`, `qk`, `d`, `fov`, `x`, `y`, `z` — see [ThreeDimensionScene](/scenes/common-scenes#threedimensionscene).

#### `Graph` API

```cpp
// Add a node with a numeric hash as its unique ID
graph.add_node(double hash);

// Add a directed edge between two node IDs
graph.add_edge(double from, double to, double opacity = 1);

// Remove an edge
graph.remove_edge(double from, double to);

// Remove a node
graph.remove_node(double id);

// Animate a node to a new vec4 position over a transition
transition_node_position(TransitionType tt, double hash, const vec4& new_position);
```

#### `GraphDrawingConfig`

Each node and edge has a `NodeRenderData` / `EdgeRenderData` profile (color, radius, label, opacity, splash effect, dashed style) managed by the `config` member of type `GraphDrawingConfig`.

#### Label Customisation

```cpp
gs.label_color   = 0xFFFFFFFF;           // ARGB color of node labels
gs.label_size    = vec2(0.4, 0.08);      // Width/height of each label box (fraction of scene)
gs.label_offset  = vec2(0, 0);           // Pixel offset of labels from node center
gs.edge_label_offset = 0.045;            // Perpendicular offset of edge labels
```

#### Demo — `GraphSpreadDemo`

```cpp
#include "Scenes/Common/CompositeScene.h"
#include "Scenes/Math/GraphScene.h"

void render_video() {
    GraphScene gs;

    gs.manager.set({
        {"q1", "1"}, {"qi", "0"}, {"qj", "0"}, {"qk", "0"},
        {"d", "900"},
        {"physics_multiplier", "40"},
    });

    stage_macroblock(SilenceBlock(10), 2);

    // Build a 50x50 grid graph
    int graph_size = 50;
    for (int i = 0; i < graph_size; i++) {
        for (int j = 0; j < graph_size; j++) {
            int hash = i + j * graph_size;
            gs.graph.add_node(hash);
            if (i > 0) gs.graph.add_edge(hash, hash - 1);
            if (j > 0) gs.graph.add_edge(hash, hash - graph_size);
        }
    }
    gs.render_microblock();
    gs.render_microblock();
}
```

### `RubiksGraphScene`

**Header:** `src/Scenes/Math/RubiksGraphScene.h`  
**Inherits:** `CompositeScene → SuperScene → Scene`

Combines a `GraphScene` with a collection of `RubiksScene` children to visualise the Cayley graph of the Rubik's Cube group. Each node in the graph can optionally display a miniature cube and/or a label.

```cpp
// Add a cube state via an algorithm string
void add_cube(const string& alg, bool cube_or_not, bool label_or_not);

// Add a cube state directly via a sticker pattern
void add_cube(const CubeStickerPattern& pattern, bool cube_or_not, bool label_or_not);

// Expand all leaf nodes by applying a move set
void add_children(
    unordered_set<string> move_set,
    bool cube_or_not,
    bool edge_label_or_not,
    bool cube_label_or_not
);

shared_ptr<GraphScene> gs;  // Direct access to the underlying graph
```

## Geometric / Topological Scenes

### `ManifoldScene`

**Header:** `src/Scenes/Math/ManifoldScene.h`  
**Inherits:** `ThreeDimensionScene → SuperScene → Scene`

Renders parametric surfaces using GPU ray-marching with a depth buffer. Manifolds are defined by RPN equations for their `x`, `y`, `z` coordinates and an optional color channel, evaluated over a `(u, v)` parameter grid. An optional texture can be mapped onto the surface.

```cpp
void add_manifold(
    const string& name,
    const string& x_eq,    // RPN equation for x(u,v)
    const string& y_eq,    // RPN equation for y(u,v)
    const string& z_eq,    // RPN equation for z(u,v)
    const string& r_eq,    // RPN equation for red channel
    const string& i_eq,    // RPN equation for green channel
    const string& u_min, const string& u_max, const string& u_steps,
    const string& v_min, const string& v_max, const string& v_steps
);

void remove_manifold(const string& name);

void set_texture(const Pixels& new_texture);  // Map a PNG texture onto the surface
```

#### Demo — `ManifoldDemo`

```cpp
#include "Scenes/Math/ManifoldScene.h"
#include "IO/PNG.h"

void render_video() {
    ManifoldScene ms;

    // Start with a flat plane
    ms.add_manifold("",
        "(a)", "(b) -1 *", "0",
        "(a)", "(b)",
        "-1", "1", "5000",
        "-1", "1", "5000"
    );

    stage_macroblock(SilenceBlock(15), 6);
    ms.manager.set({{"d", "4"}});

    Pixels pix;
    png_to_pix(pix, "../earth_tiny");
    ms.set_texture(pix);

    // Animate the manifold equations to describe a sphere
    ms.manager.transition(MICRO, {
        {"manifold_x", "(a) cos (b) sin *"},
        {"manifold_y", "(b) cos"},
        {"manifold_z", "(a) sin (b) sin *"},
        {"manifold_a_min", "0"},
        {"manifold_a_max", "pi 2 *"},
        {"manifold_b_min", "0"},
        {"manifold_b_max", "pi"},
    });
    ms.render_microblock();
    ms.render_microblock();

    // Spin the camera
    ms.manager.transition(MICRO, {
        {"q1", "{t} 2 / sin"},
        {"qi", "{t} 2 * sin .6 *"},
        {"qj", "{t} 2 / cos"},
        {"qk", "0"},
    });
    ms.render_microblock();
    ms.render_microblock();
    ms.render_microblock();
    ms.render_microblock();
}
```

## Cellular Automaton

### `ConwayScene`

**Header:** `src/Scenes/Math/ConwayScene.h`  
**Inherits:** `CoordinateScene → Scene`

Renders Conway's Game of Life (or any Life-like automaton) on a GPU-accelerated bitboard grid. The grid advances one generation per `on_end_transition_extra_behavior` call.

## Rubik's Cube

### `RubiksScene`

**Header:** `src/Scenes/Math/RubiksScene.h`  
**Inherits:** `ThreeDimensionScene → SuperScene → Scene`

Renders an animated 3-D Rubik's Cube using the inherited 3-D camera. Moves are applied via Singmaster notation tokens, which are animated smoothly across a microblock.

```cpp
RubiksScene(const vec2& dimensions = vec2(1, 1));
RubiksScene(const CubeStickerPattern& pattern, const vec2& dimensions = vec2(1, 1));

// Apply a single move token (e.g. "R", "B'", "U2")
void exec_move_from_slice(const string& token);

Rubiks the_cube;  // Direct access to the underlying cube state
```

Camera control is inherited from `ThreeDimensionScene` (`q1/qi/qj/qk`, `d`, `fov`). The state variable `internal_plastic_opacity` controls whether the cube's internal plastic is visible (useful for exploded-view effects).

#### Demo — `RubiksDemo` (excerpt)

```cpp
#include "Scenes/Math/RubiksScene.h"

void render_video() {
    RubiksScene rs;

    quat yaw   = quat(cos(0.125 * M_PI), 0, sin(0.125 * M_PI), 0);
    quat pitch = quat(cos(-0.098 * M_PI), sin(-0.098 * M_PI), 0, 0);
    quat combined = pitch * yaw;

    stage_macroblock(SilenceBlock(1), 1);
    rs.manager.transition(MACRO, {
        {"q1",  to_string(combined.u)},
        {"qi",  to_string(combined.i)},
        {"qj",  to_string(combined.j)},
        {"qk",  to_string(combined.k)},
        {"d",   "1.4"},
        {"fov", "0.25"},
    });
    rs.render_microblock();

    stage_macroblock(SilenceBlock(10), 10);
    rs.exec_move_from_slice("R");   rs.render_microblock();
    rs.exec_move_from_slice("B'");  rs.render_microblock();
    rs.exec_move_from_slice("B2");  rs.render_microblock();
    rs.exec_move_from_slice("U");   rs.render_microblock();
    rs.exec_move_from_slice("R'");  rs.render_microblock();
    // ...
}
```

## Function Scenes

### `RealFunctionScene`

**Header:** `src/Scenes/Math/RealFunctionScene.h`  
**Inherits:** `CoordinateScene → Scene`

Plots real-valued functions `f(x)` on a coordinate grid. The function formula is supplied as an RPN state equation referencing `{a}` as the x-variable, enabling smooth animated transitions between different function shapes. Two function colors are predefined (`0xFF0088FF` and `0xFFFF0088`).

```cpp
// Evaluate the function at x, interpolating between current and transitional formulas
float call_the_function(const float x, const ResolvedStateEquation& re);

void render_functions();  // Called internally by draw()
```

</Tip>
