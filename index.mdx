SwapTube is the rendering framework behind the [2swap YouTube channel](https://www.youtube.com/@twoswap). It gives you a scene graph, a declarative state animation system, and a two-tier timeline — all running on your GPU via CUDA or HIP — so you can write a C++ project file and get a fully timed, narrated MP4 out the other side.

## What SwapTube Does

SwapTube handles everything between "I have a mathematical idea" and "I have a YouTube-ready MP4":

- **GPU rendering** — Every frame is computed on your NVIDIA (CUDA) or AMD (HIP) GPU. Complex scenes like Mandelbrot sets, 4D rotations, and pendulum fractals render at real-time speeds.
- **Audio-visual synchronization** — You write narration text inline in your project file. SwapTube derives audio filenames, writes `record_list.tsv`, and aligns video segments to the exact duration of each recorded audio clip.
- **Declarative animation** — The `StateManager` tracks variables as a dependency graph of equations. Call `transition()` once and SwapTube smoothly interpolates position, opacity, zoom, or any parameter over the duration of a Macroblock or Microblock — no manual keyframing.
- **Mandatory smoketest** — Every `./go.sh` run first executes a fast smoketest at 320×180. Only after it passes does the full render begin, saving you from discovering a crash three hours into a 4K render.

## How a Project Works

```cpp MyProject.cpp
#include "Scenes/Math/MandelbrotScene.h"

void render_video() {
    MandelbrotScene ms;

    // Stage a 4-second silence, rendered in 2 microblocks
    stage_macroblock(SilenceBlock(4), 2);
    ms.render_microblock();

    // Animate zoom from default to 1.0 over the second microblock
    ms.manager.transition(MICRO, "zoom", "1");
    ms.render_microblock();
}
```

Run it with:

```bash
./go.sh MyProject 1920 1080 30
```

<Steps>
  <Step title="Install dependencies">
    Install CMake, Ninja, FFmpeg dev libs, CUDA or HIP, and optional LaTeX/PNG libs. See the [Installation guide](/installation).
  </Step>
  <Step title="Write a project file">
    Create `src/Projects/MyProject.cpp` with a `render_video()` function. Pick scenes from the [scene library](/scenes/overview), stage macroblocks, and call `render_microblock()`.
  </Step>
  <Step title="Run go.sh">
    Execute `./go.sh MyProject 1920 1080 30`. SwapTube smoketests, then renders your video to `out/MyProject/<timestamp>/`.
  </Step>
  <Step title="Record audio">
    After the smoketest populates `media/MyProject/record_list.tsv`, run `python record_audios.py` to record your narration clips. Re-run `go.sh` for the final render with audio.
  </Step>
</Steps>
